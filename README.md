# Ziye (Jerry) HONG Personal Website

This repository hosts my personal website on GitHub Pages:

https://hongzy7.github.io

## About

The site introduces my background in mechanical engineering, robotics, intelligent systems, product design, research projects, competitions, publications, and patents.

## Website Features

- Bilingual content: English and Chinese
- Language preference based on the visitor's browser language, with manual `zh` / `en` switching
- Light and dark themes based on the visitor's system preference, with manual theme switching
- Top navigation for About Me, Education, and Work Experience
- Resume PDF link

## Repository Structure

- `index.md`: main website content
- `_layouts/default.html`: page layout and navigation
- `_sass/jekyll-theme-minimal.scss`: visual styles, light/dark theme variables, responsive layout
- `assets/js/preferences.js`: language and theme switching behavior
- `index.assets/`: portrait and resume files

## Notes

This site is built with GitHub Pages and the Jekyll minimal theme. The local `_local-preview/` folder, if present, is only for quick local preview and is not required for GitHub Pages deployment.
